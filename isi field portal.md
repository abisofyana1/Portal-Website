## 📝 Pilihan Teks Deskripsi Project (Copy - Paste)

### Opsi 1: Bahasa Indonesia (Rekomendasi - Detail & Profesional)
```text
PortalCXC adalah platform enterprise web portal dan knowledge management terintegrasi yang dirancang khusus untuk operasional Contact Center. Dilengkapi dengan antarmuka dinamis berbasis peran (Multi-Role: Super Admin, Admin Unit, dan Agent), sistem pengelolaan berita/informasi (News Carousel & Running Text), pemantauan log aktivitas pengguna, diagnostik keamanan & error sistem otomatis secara real-time, serta mode interaktif live demo tanpa ketergantungan database eksternal.
```

### Opsi 2: Bahasa Indonesia (Singkat & Ringkas)
```text
Aplikasi enterprise portal dan knowledge center terintegrasi untuk divisi Contact Center. Memiliki fitur multi-role management, pelacakan aktivitas dan error sistem real-time, kustomisasi layout dinamis, serta navigasi responsif multi-device dengan dukungan live demo statis di GitHub Pages.
```

### Opsi 3: Bahasa Inggris (English Version)
```text
PortalCXC is an integrated enterprise portal and knowledge management platform tailored for Contact Center operations. It features multi-role access control (Super Admin, Unit Admin, and Agent), dynamic news announcements, real-time activity tracking, automated system error diagnostic tools, and fully responsive cross-platform layout deployed seamlessly on GitHub Pages.
```
